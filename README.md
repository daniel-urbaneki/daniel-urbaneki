## 🚀 Projetos em Destaque

### [Harness Figma LP Generator](https://github.com/daniel-urbaneki/harness-figma-lp-generator)

Projeto focado na criação de Landing Pages estáticas de alta fidelidade a partir de layouts do Figma, utilizando HTML, CSS e JavaScript.

O projeto utiliza uma abordagem estruturada de desenvolvimento assistido por IA, com etapas definidas para análise do layout, planejamento, tratamento de assets, implementação, responsividade, comparação visual e validação.

**Principais objetivos técnicos:**
- Transformar layouts do Figma em interfaces fiéis ao design original.
- Estruturar o processo de desenvolvimento por etapas e regras documentadas.
- Automatizar verificações de qualidade com lint, testes, tipagem estática e formatação.
- Integrar validações automatizadas ao pipeline de CI.
- Melhorar a consistência e a previsibilidade das entregas com Claude Code.
